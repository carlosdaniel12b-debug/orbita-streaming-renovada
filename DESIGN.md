# Órbita — criterios de la actualización

Se mantiene la identidad espacial, las fuentes locales Syne (titulares) y Manrope (texto), los precios y las funciones existentes.

Paleta: espacio #040912; panel #0d1c29; texto #e6f2f2; texto secundario #b2c8d0; acento #a7ead8.

Recorrido de la portada:
Hero por capas → plataformas → combo → contratación → historias → recomendación inmersiva → arcade → preguntas.

La introducción es el único momento de entrada elaborado. Se muestra una vez por sesión; repetirla es una acción explícita. Los contenidos inferiores no dependen de animaciones para aparecer.

El cristal usa un reflejo superior fino, fondo oscuro legible y desenfoque limitado a controles o paneles. En móvil, las tarjetas repetidas usan un fondo equivalente sin desenfoque para reducir coste. Las imágenes no se desenfocan.

Guías utilizadas: Impeccable (animación, estructura, robustez), Anthropic Frontend Design (jerarquía y composición) y Vercel Web Design Guidelines (interacciones y accesibilidad).
